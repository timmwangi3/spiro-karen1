Supported connection strategy

USB scanners behave like keyboards; cameras use the browser camera; printers can use Windows spool or LAN ESC/POS; battery stations use LAN/Wi-Fi MQTT/HTTPS.
USB → local Windows drivers / serial bridge · LAN/Wi-Fi → TCP 9100 or station gateway · Bluetooth → Windows paired device / keyboard profile · Camera → browser permission · Battery station → authenticated MQTT/HTTPS gateway.
